Walker CRM

Curso prático — Terminal + Node.js

Passo 1 — Criar o projeto

Crie a pasta principal do Walker CRM e entre nela.

mkdir walker-crm

cd walker-crm

Passo 2 — Criar a pasta public

A pasta public vai guardar os arquivos da parte visual do CRM.

mkdir public

cd public

Passo 3 — Criar os arquivos do site

Aqui vamos criar HTML, CSS e JavaScript.

touch index.html

touch style.css
touch app.js

Passo 4 — Voltar para a pasta principal

Voltamos da pasta public para walker-crm.

cd ..

Passo 5 — Criar os arquivos do servidor

Vamos criar o servidor Node.js e o arquivo que futuramente poderá guardar nossos dados.

touch server.js

touch banco.json

Passo 6 — Preparar o Node.js

Este comando cria o package.json do projeto.

npm init -y

Passo 7 — Instalar o Express

O Express será usado para criar o servidor e as APIs do Walker CRM.

npm install express

Resultado esperado

walker-crm/
├── server.js
├── package.json
├── banco.json
├── package-lock.json
├── node_modules/
└── public/
    ├── index.html
    ├── style.css
    └── app.js
